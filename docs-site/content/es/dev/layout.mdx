## Por dónde empezar

**Añadir cosas a la API de Lua.** La parte de Java es la tabla `native` de `computer/LuaComputer.java`; `prelude.lua` la convierte en las globales que ven los programas y luego la suelta. Añade también los nombres nuevos a `client/editor/LuaApi.java` para que el editor los sugiera.

**Funciones nuevas de dispositivos.** `bus/DeviceDrivers.java` decide qué puede hacer un bloque según lo que es: cinético, inventario de objetos, tanque de fluidos. Las lecturas van detrás de un puerto de salida y las escrituras detrás de uno de entrada. Si el valor de una lectura puede cambiar, añádelo a `snapshot` para que `onChange` se entere.

**La red.** `bus/BusData.java` guarda cada pieza, tramo de cable y nombre de dispositivo por dimensión, fuera de los bloques. `bus/Bus.java` tiene las reglas para colocar piezas y encontrar los dispositivos a los que llega un ordenador. `bus/CableRoute.java` calcula los recorridos colgantes y por superficie.

**El editor.** `client/editor/ComputerEditorScreen.java` (ventana, paneles, pestañas), `CodeEditor.java` (edición de texto) y `Completions.java` (qué sugerir).

**El disco de un ordenador.** `computer/ComputerFiles.java`, con los límites.

**Un bloque nuevo.** Regístralo en `registry/ModBlocks.java`, genera su modelo con `tools/models/gen_models.py` y luego `./gradlew runData`.
