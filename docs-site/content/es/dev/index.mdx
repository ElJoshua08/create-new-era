Esta sección es para quien trabaja en Create: New Era. Si lo que quieres es jugar con el mod, ve a la [Guía](../guide/index.mdx).

El mod es de dominio público bajo The Unlicense, así que haz un fork, cámbialo y publícalo como quieras.

## Empezar

```sh title="Terminal"
git clone https://github.com/ElJoshua08/create-new-era.git
cd create-new-era
./gradlew runClient     # la primera vez descarga el modpack de desarrollo en run/
```

Solo necesitas un JDK 17 o posterior para arrancar Gradle. Él se descarga los JDK que hacen falta: JDK 21 para compilar, y el JetBrains Runtime para las partidas de desarrollo con recarga en caliente. En Windows usa `gradlew.bat`.

Luego, con el juego todavía abierto, cambia algo de Java y ejecuta:

```sh title="Terminal"
./gradlew hotswap       # recompila y mete las clases cambiadas en el juego abierto
```
