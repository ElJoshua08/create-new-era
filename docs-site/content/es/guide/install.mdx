Create: New Era es un mod de NeoForge para Minecraft 1.21.1. Necesita Create y nada más: la máquina virtual de Lua que usa ([Cobalt](https://github.com/cc-tweaked/Cobalt)) va dentro del jar, así que no hace falta CC: Tweaked.

<Download />

## Requisitos

| Mod | Versión | |
| --- | --- | --- |
| Minecraft | 1.21.1 | |
| NeoForge | 21.1.265 o posterior | |
| Create | 6.0.10 o posterior | |
| Create: Aeronautics | 1.3 o posterior | opcional |
| Sable | 2.0 o posterior | opcional, viene con Aeronautics |

Todo funciona sin Aeronautics. Con él, los programas también pueden leer y pilotar barcos: la palanca de aceleración, el timón, el ensamblador físico, la mesa de navegación, el sensor óptico, las hélices y los sensores de Aeronautics aparecen como dispositivos, su Linked Typewriter manda cada tecla a los programas, los instrumentos de vuelo leen el barco en el que están montados, y los puertos y cables viajan con el barco cuando se ensambla.

La última versión es la del botón de descarga de arriba. Lo que cambió en cada una está en sus [notas de la versión en GitHub](https://github.com/ElJoshua08/create-new-era/releases).

## Pasos

<Steps>
<Step>

Instala NeoForge 21.1.265 o posterior para Minecraft 1.21.1 y arranca el juego una vez para que cree la carpeta `mods`.

</Step>
<Step>

Pon Create 6.0.10 o posterior en `mods`.

</Step>
<Step>

Pon el jar de Create: New Era en `mods` y arranca el juego.

</Step>
</Steps>

En un servidor, el mod va tanto en el servidor como en cada cliente.

## Dónde están los bloques

Todo está en la pestaña creativa **Create: New Era**, justo después de las de Create. Pasa el ratón por un objeto y mantén <kbd>Shift</kbd> para ver su descripción, <kbd>Ctrl</kbd> para sus controles y <kbd>W</kbd> para ver su escena de Ponder. Tienen una el ordenador de latón, la pantalla de latón, los puertos de datos, el hub de puertos, la bobina y el empalme, los controles de panel y el altavoz, los instrumentos de vuelo, el adaptador universal y el servo de rodamiento.

Para supervivencia, cada bloque tiene una receta hecha con piezas de Create: mira [Recetas](./recipes.mdx). La progresión en supervivencia aún no está terminada, así que cambiarán.
