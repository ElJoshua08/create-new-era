Create: New Era is a NeoForge mod for Minecraft 1.21.1. It needs Create, and nothing else: the Lua VM it uses ([Cobalt](https://github.com/cc-tweaked/Cobalt)) is inside the jar, so you don't need CC: Tweaked.

<Download />

## Requirements

| Mod | Version | |
| --- | --- | --- |
| Minecraft | 1.21.1 | |
| NeoForge | 21.1.265 or newer | |
| Create | 6.0.10 or newer | |
| Create: Aeronautics | 1.3 or newer | optional |
| Sable | 2.0 or newer | optional, comes with Aeronautics |

Nothing in this version needs Aeronautics. The mod only declares it so the two load in the right order when you have both.

## Steps

<Steps>
<Step>

Install NeoForge 21.1.265 or newer for Minecraft 1.21.1, and start the game once so it creates the `mods` folder.

</Step>
<Step>

Put Create 6.0.10 or newer in `mods`.

</Step>
<Step>

Put the Create: New Era jar in `mods` and start the game.

</Step>
</Steps>

On a server, the mod goes on both the server and every client.

## Finding the blocks

Everything is in the **Create: New Era** creative tab, right after Create's tabs. Hover an item and hold <kbd>Shift</kbd> for its description, <kbd>Ctrl</kbd> for its controls, and <kbd>W</kbd> to watch its Ponder scene. The Brass Computer, Brass Screen, Universal Adapter, Bearing Servo and the panel controls have one.

For survival, every block has a recipe made from Create parts: see [Recipes](./recipes.mdx). Survival progression isn't finished in this version, so expect some of them to change.
