```text
src/main/java/com/createnewera/
  CreateNewEra.java          mod entry point: registers content, config, network, events

  computer/                  Brass Computer: block, block entity, Lua VM, files, sides
  client/editor/             the in-game editor: code view, suggestions, the Lua API list, layout
  client/bus/                drawing ports and cables, the device highlight
  client/render/             the computer's renderer
  network/                   payloads between client and server
  ponder/                    Ponder scenes
  registry/                  blocks, items, block entities, components, recipes, creative tab, lang
  config/                    client config
  gametest/                  GameTests

  data/create_new_era/lua/prelude.lua   turns the Java side into the Lua API
```

## Where to start

**Adding to the Lua API.** The Java side is the `native` table in `computer/LuaComputer.java`; `prelude.lua` turns it into the globals programs see and then drops it. Add new names to `client/editor/LuaApi.java` too, so the editor suggests them.

**New device functions.** `bus/DeviceDrivers.java` decides what a block can do from what it is: kinetic, item inventory, fluid tank. Readers go behind an output port, writers behind an input port. If a reader's value can change, add it to `snapshot` so `onChange` notices.

**The network.** `bus/BusData.java` stores every part, cable span and device name per dimension, outside the blocks. `bus/Bus.java` has the rules for placing parts and finding the devices a computer can reach. `bus/CableRoute.java` works out hanging and surface routes.

**The editor.** `client/editor/ComputerEditorScreen.java` (window, panels, tabs), `CodeEditor.java` (text editing) and `Completions.java` (what to suggest).

**A computer's disk.** `computer/ComputerFiles.java`, with the limits.

**A new block.** Register it in `registry/ModBlocks.java`, generate its model with `tools/models/gen_models.py`, then `./gradlew runData`.
