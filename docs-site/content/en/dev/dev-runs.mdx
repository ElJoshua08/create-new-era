title: Dev runs
description: The modpack runClient downloads, and how to switch parts of it off.
---

`runClient` downloads a realistic modpack into `run/` the first time, so the mod gets tested against what players actually run.

- Sodium, Lithium, ModernFix, FerriteCore, ImmediatelyFast and Entity Culling
- JEI
- Iris, with Complementary Reimagined (switched on at first launch) and Complementary Unbound
- Create: Aeronautics and Sable

Every file is pinned to a Modrinth URL and checked against its SHA-1; a mismatch stops the build. The mods go into the run folders like a real install, not onto the classpath, so client-only mods never reach the dev server.

The server and GameTest runs use `run/server/` and only get Aeronautics and Sable. Datagen runs in `run/data/`, because the client-only mods in `run/` hang it.

## Switches

In `gradle.properties`:

```properties title="gradle.properties"
# Sodium and the optimisation mods in runClient
dev_client_mods=true
# JEI in runClient
dev_jei=true
# Iris and the Complementary shaderpacks in runClient
dev_shaders=true
# Create: Aeronautics and Sable in every run
dev_aeronautics=true
# live code reloading, see Live reloading
dev_hotswap=true
# a world under run/saves to open straight away; empty for the title screen
dev_world=
```

Keep comments on their own lines: in a `.properties` file, a `#` after a value is part of the value.

`dev_world` takes the name of a save folder in `run/saves/`. If the folder exists, `runClient` skips the title screen and opens that world. Leave it empty for the title screen.

Turning a switch off stops new downloads, but files already in `run/mods` stay there. Delete them by hand if you want them gone.

To bump a version, replace its URL and SHA-1 in `gradle/dev-mods.gradle`. The downloads run as the `setupDevClient` and `setupDevServer` tasks, before the matching run tasks.
