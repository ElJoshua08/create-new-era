This section is for people working on Create: New Era itself. If you want to play with the mod, the [Guide](../guide/index.mdx) is the place.

The mod is public domain under The Unlicense, so fork it, change it and ship it however you like.

## Quick start

```sh title="Terminal"
git clone https://github.com/ElJoshua08/create-new-era.git
cd create-new-era
./gradlew runClient     # the first run downloads the dev modpack into run/
```

You only need a JDK 17 or newer to start Gradle. It downloads the JDKs it needs on its own: JDK 21 to build, and the JetBrains Runtime for dev runs with live reloading. On Windows use `gradlew.bat`.

Then, with the game still open, change some Java and run:

```sh title="Terminal"
./gradlew hotswap       # recompile and push the changed classes into the running game
```
