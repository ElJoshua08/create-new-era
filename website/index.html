Programmable automation for Create. Brass computers that run Lua, a data bus that reaches every machine, buildable control panels, and a mechanical flip-pixel screen.

The idea

CC: Tweaked lets you program Minecraft. Create: New Era is meant to feel like part of Create itself: brass computers running Lua, a data bus that reaches every machine, control desks you build block by block, and a screen made of moving parts. Built for factories, fluids, trains and Create: Aeronautics ships alike.

Works today

  • The Brass Computer runs Lua programs, written in its own in-game editor
  • Programs read and send redstone on all six sides
  • Brass Screens facing the same way join into one pane
  • 13 blocks and items with recipes, Create-style tooltips and a Ponder scene for each

Not yet

  • The data bus, drawing on screens, wired panel controls and the servo. See the roadmap.

Write a program

The Brass Computer runs Lua today. Right-click it to open the editor, write a program and press Run. Every new computer starts with this one, which blinks a redstone signal out of its back.

What a program can do today

print(...)
Writes a line to the console under the editor.
sleep(seconds)
Waits in game time, 20 ticks a second. Also os.sleep.
os.clock()
Seconds since the program started.
redstone.getInput(side)
Signal coming in, as on/off. getAnalogInput gives 0 to 15.
redstone.setOutput(side, on)
Signal going out. setAnalogOutput takes 0 to 15.

Sides are named from the computer's front: front, back, left, right, top, bottom. A program that loops without sleeping only slows itself down, never the server.

The machines

Built from Create parts you already make: brass casing, electron tubes, precision mechanisms. Hover, tap or hold Shift to read each tooltip, and Ctrl for controls, the way you would in game. In game, hold W over any of them for its Ponder scene.

Brass ComputerHold [Shift]Hold [Ctrl]

Runs Lua programs you write in its built-in editor. For now they work with redstone; the data bus comes next.

A screen made of moving parts

The Brass Screen is designed as a grid of physical flip pixels. When the picture changes, each pixel turns over on its axis: the old colour on the front, the new one on the back. Brush across the plates. Drawing on screens arrives in phase 4.

  • 48 pixels per block

    Screens facing the same way already merge into one pane in game, and the brass frame between them disappears. A 3 × 2 screen has 132 × 84 plates inside its bezel, like the board at the top of this page.

  • Only what changes moves

    A pixel that already shows the right colour stays still. A counter going up turns only its digits.

  • Square plates or round discs

Roadmap

Seven phases, in order. The first is done and the second is well under way; everything after that is planned, not built.

  1. Phase 1 Done

    Foundation

    Blocks, recipes, creative tab, Create and Aeronautics dependencies.

  2. Phase 2 In progress

    Lua runtime

    A sandboxed VM on the computer with an in-game editor. The VM, the editor and the redstone API are done; files and multiple programs are still to come.

  3. Phase 3

    Data bus

    Cables and adapters that expose Create machines as typed peripherals.

  4. Phase 4

    Flip-pixel screens

    Multiblock screens and a declarative UI library for good-looking dashboards. Screens already join into one pane.

  5. Phase 5

    Panels

    Wire the controls to programs.

  6. Phase 6

    Aeronautics

    Servos, sensors, then autonomous and remote-piloted drones with signal towers.

  7. Phase 7

    Visual programming

    Node-based programming for people who'd rather not write Lua.
