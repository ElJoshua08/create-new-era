Client config

Create: New Era has one client-side option today. Client options are per player: changing them on your machine doesn't affect anyone else on a server.

Pixel shape

Brass Screens are made of physical flip pixels. This option picks what each pixel looks like: a square plate or a round disc. It's purely visual, so each player picks their own.

KeyValuesDefault
screen.pixelShapeSQUARE, DISCSQUARE

Screens don't draw their pixels in game yet (that's phase 4), so the option is already saved but has no visible effect. You can try both shapes on the home page.

In game

Open Mods, select Create: New Era and press Config. The option is under Screens → Pixel shape.

In the file

NeoForge names a mod's client config <modid>-client.toml, so the file is config/create_new_era-client.toml inside your game folder:

[screen]
	#Shape of each flip pixel on brass screens. Purely visual, so each player picks their own.
	#Allowed Values: SQUARE, DISC
	pixelShape = "SQUARE"
