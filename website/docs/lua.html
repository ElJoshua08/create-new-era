Reference

Lua API

The Brass Computer runs programs written in Lua. They run on Cobalt, the Lua VM from CC: Tweaked. This page is everything a program can reach today: the console, time and redstone.

The data bus, which lets programs talk to Create machines, is phase 3. Until then programs work with redstone.

The editor#

Right-click a Brass Computer to open its editor. (With Create's wrench in hand, right-click turns the computer instead, and its sides turn with it.) The editor has three parts:

  • Code, with Lua syntax highlighting. It autosaves while you type; a program can be up to 16,384 characters.
  • Console under the code. It shows print output, errors and status lines (Running, Stopped, Program finished, Restarted after the world loaded). It keeps the last 100 lines.
  • Redstone panel, showing what comes in and goes out on each side, live.

How programs run#

  • While a program runs, the computer's screen lights up. It keeps running when nobody has the editor open.
  • Each computer gets a slice of time every tick. A program that loops without sleeping is paused mid-instruction and picked up next tick, so it slows itself down instead of the server.
  • sleep counts game time and rounds up to whole ticks (20 a second). sleep(0) waits exactly one tick.
  • When a program ends or hits an error, it stops and the console says why. Its outputs stay as they were. Pressing Stop also turns every output off.
  • A program that was running when the world was saved starts again from the top when it loads. Variables aren't kept.

Reference#

Console and time#

FunctionWhat it does
print(...)Writes its arguments to the console as one line, converted with tostring and separated by tabs.
sleep(seconds)Waits that long in game time. No argument means one tick. Anything but a number is an error. Also available as os.sleep.
os.clock()Seconds of game time since the program started.

Redstone#

The redstone table, also reachable as rs. Every function takes a side name as its first argument.

FunctionReturnsWhat it does
getInput(side)booleanWhether any signal comes in on that side.
getAnalogInput(side)0 to 15The strength of the signal coming in.
setOutput(side, on)Sends a full signal (15) out of that side, or turns it off.
setAnalogOutput(side, strength)Sends a signal of 0 to 15. Other values are an error.
getOutput(side)booleanWhether this computer is sending anything out of that side.
getAnalogOutput(side)0 to 15The strength this computer sends out of that side.
getSides()tableThe six side names, in this order: front, back, left, right, top, bottom.

Sides are named from the computer's front: front, back, left, right, top, bottom. Left and right are as you see them standing in front of it. Any other name stops the program with an error such as unknown side 'north'.

Outputs are strong signals: besides the block next to that side, they also reach whatever sits behind it.

Libraries#

Programs get Lua's base functions (pairs, ipairs, tostring, pcall and the rest) and the string, table, math, coroutine, utf8 and bit32 libraries. os only has clock and sleep. There's no file or network access.

Examples#

Each one is a whole program: paste it into the editor and press Run.

Blink#

The program every new computer starts with. It sends a pulse out of the back twice a second, forever.

Lua
-- Blinks a redstone signal out of the back.
-- Edit me, then press Run (Ctrl+R).
while true do
  redstone.setOutput("back", true)
  sleep(0.5)
  redstone.setOutput("back", false)
  sleep(0.5)
end

Repeat a signal#

Copies whatever comes in from the back to the front, once a tick. Put a lever behind the computer and a lamp in front.

Lua
while true do
  rs.setOutput("front", rs.getInput("back"))
  sleep(0) -- waits one tick
end

Count pulses#

Counts rising edges on the left and prints the total each time it goes up.

Lua
local count, was = 0, false
while true do
  local on = rs.getInput("left")
  if on and not was then
    count = count + 1
    print("pulses: " .. count)
  end
  was = on
  sleep(0)
end

Fade up#

Raises the analog output on top from 0 to 15, then stops. The output stays at 15 after the program finishes.

Lua
for strength = 0, 15 do
  rs.setAnalogOutput("top", strength)
  sleep(0.25)
end
print("done after " .. os.clock() .. " s")

Read every side#

Prints the signal strength coming into each side once.

Lua
for _, side in ipairs(rs.getSides()) do
  print(side, rs.getAnalogInput(side))
end
