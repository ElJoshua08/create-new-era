Lua API reference

Programs run on Cobalt, the Lua VM from CC: Tweaked. This is everything they can reach today: the console, time, other files and redstone.

The data bus, which lets programs talk to Create machines, is phase 3. Until then programs work with redstone.

Globals#

FunctionWhat it does
print(...)Writes its arguments to the console as one line, converted with tostring and separated by tabs.
sleep(seconds)Waits that long in game time, rounded up to whole ticks. No argument means one tick. Anything but a number is an error.
require(name)Runs another file on this computer once and returns what it returned. See Files and require.

os#

Only these three; there's no os.time, os.date or file access.

FunctionWhat it does
os.clock()Seconds of game time since the program started.
os.sleep(seconds)Same as sleep.
os.speed()The computer's rotation speed in RPM, negative when the shaft turns the other way. At 0 the program is paused, so it never sees 0 for long.

redstone#

Also reachable as rs. Every function takes a side name first: front, back, left, right, top or bottom, named from the computer's front. Any other name stops the program with an error such as unknown side 'north'.

FunctionReturnsWhat it does
getInput(side)booleanWhether any signal comes in on that side.
getAnalogInput(side)0 to 15The strength of the signal coming in.
setOutput(side, on)Sends a full signal (15) out of that side, or turns it off.
setAnalogOutput(side, strength)Sends a signal of 0 to 15. Other values are an error.
getOutput(side)booleanWhether this computer is sending anything out of that side.
getAnalogOutput(side)0 to 15The strength this computer sends out of that side.
getSides()tableThe six side names, in the order front, back, left, right, top, bottom.

Outputs are strong signals: besides the block next to that side, they also reach whatever sits behind it.

Libraries#

The standard string, table, math, coroutine, utf8 and bit32 libraries are there, and so are the base functions: pairs, ipairs, next, select, type, tostring, tonumber, error, assert, pcall, xpcall, setmetatable, getmetatable, rawget, rawset, rawequal, rawlen, load. The editor's suggestions list each one with a short description.

Errors#

An error stops the program and the console shows it in red, starting with the file and line: startup.lua:4: attempt to call a nil value. Click it to jump there. Use pcall to catch errors you expect.
