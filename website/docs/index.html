Create: New Era

Programmable automation for Create on NeoForge 1.21.1. Brass Computers run on rotational force like any Create machine, run Lua programs that read and drive redstone today, and will reach every Create machine through a data bus.

Early development (phase 2). The Brass Computer runs Lua with a multi-file editor, powered by a shaft, and drives redstone. Screens join into big panes but can't draw yet. The data bus, drawing on screens and the panel controls come next.

Your first program#

  1. Place a Brass Computer and run a shaft into its back from any rotation source: a water wheel, a windmill, or a Creative Motor in creative. Computers only run while they turn.
  2. Put a redstone lamp on top of it.
  3. Right-click the computer. The editor opens on startup.lua, which every new computer comes with:
Lua
-- Blinks a redstone signal out of the top: put a lamp on it.
-- Edit me, then press Run (Ctrl+R).
while true do
  redstone.setOutput("top", true)
  sleep(0.5)
  redstone.setOutput("top", false)
  sleep(0.5)
end
  1. Press Run or Ctrl+R. The computer's screen lights up, the lamp blinks twice a second and the status bar shows the speed it's running at.

Change 0.5 to another delay and press Ctrl+R again: the program restarts with your change.
