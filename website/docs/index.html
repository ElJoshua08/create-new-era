Getting started

Create: New Era is an add-on for Create on NeoForge 1.21.1. It adds brass computers, a data bus, buildable control panels and a mechanical flip-pixel screen. This page covers what exists today and how to install it.

Early development (phase 2). The Brass Computer runs Lua and drives redstone, with an in-game editor. Screens join into big panes but can't draw yet. The data bus, drawing on screens and the panel controls come next.

What works today

  • The Brass Computer runs Lua. Right-click it to open its editor, write a program and press Run. Programs read and send redstone on all six sides. See the Lua API.
  • Brass Screens placed side by side, facing the same way, join into one pane and the frame between them disappears. They don't draw anything yet.
  • 13 blocks and items in their own Create: New Era creative tab, right after Create's tabs: four machines, the Control Plate and eight panel controls.
  • Recipes for every block, using vanilla crafting, Create's Mechanical Crafting and Item Application. See Blocks and recipes.
  • Every block can be rotated with Create's wrench, has collision shapes fitted to its model and is mined with a pickaxe.
  • Create-style tooltips: hold Shift over an item for its summary and details, Ctrl for its controls.
  • A Ponder scene for every block: hold W over the item, Create's usual Ponder key. The Control Plate and the eight controls share one scene.
  • English and Spanish translations.

Installation

No release yet. When the first build is published it will be on the GitHub releases page. Until then you can build the jar from source.

NeedsVersion
Minecraft1.21.1
NeoForge21.1.265 or newer
Create6.0.10 or newer
Create: Aeronautics1.3 or newerOptional
  1. Install NeoForge 21.1.265 or newer for Minecraft 1.21.1, and start the game once so it creates the mods folder.
  2. Put Create 6.0.10 or newer in mods.
  3. Optionally add Create: Aeronautics 1.3 or newer, with whatever it requires according to its own page.
  4. Put the Create: New Era jar in mods and launch.

First steps

Open the creative inventory and find the Create: New Era tab, the one right after Create's own tabs. In survival, every block has a recipe built from Create parts: brass casing, electron tubes, precision mechanisms, andesite alloy.

Panel controls all start from a Control Plate: craft 2 andesite alloy and a brass sheet into four plates, then combine a plate with one part to make each control.

Place a Brass Computer and right-click it. Every new computer comes with a program that blinks a redstone signal out of its back: put redstone dust or a lamp behind it and press Run (Ctrl+R). Its screen lights up while a program runs. The Lua API page covers the rest.

Hover any of the mod's items and hold Shift to read what it's for, or W to watch its Ponder scene. Apart from the computer and the way screens join, the blocks are placeable, rotatable decoration for now while the systems behind them are built.
