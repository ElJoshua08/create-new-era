Installing

Create: New Era is a NeoForge mod for Minecraft 1.21.1 and needs Create.

No release yet. When the first build is published it will be on the GitHub releases page. Until then you can build the jar from source.

Requirements#

NeedsVersion
Minecraft1.21.1
NeoForge21.1.265 or newer
Create6.0.10 or newer
Create: Aeronautics1.3 or newerOptional

Steps#

  1. Install NeoForge 21.1.265 or newer for Minecraft 1.21.1 and start the game once, so it creates the mods folder.
  2. Put Create 6.0.10 or newer in mods.
  3. Optionally add Create: Aeronautics 1.3 or newer, with whatever its own page says it needs.
  4. Put the Create: New Era jar in mods and launch.

The Lua VM, Cobalt, is bundled inside the jar. You don't need CC: Tweaked.

Finding the blocks#

Everything is in the Create: New Era creative tab, right after Create's tabs. In survival, every block has a recipe made from Create parts: see Blocks and recipes. The Brass Computer needs rotation in its back to run, like any Create machine; see Rotation. Hold Shift over an item for its tooltip, Ctrl for its controls, and W for its Ponder scene.
