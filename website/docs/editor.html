Guide · Programming

The editor

Right-click a Brass Computer to open its editor, a small VS Code-like window with file tabs, a console, a side panel and suggestions as you type.

With Create's wrench in your hand, right-click turns the computer instead of opening the editor. The game doesn't pause while the editor is open, and it closes if you walk more than 8 blocks away.

Layout#

  • Title bar with Run and Stop. Drag it to move the window, double-click it (or use its button) to maximise.
  • Tabs for the files you have open, above the code.
  • Code with Lua syntax highlighting and line numbers.
  • Status bar with the program's state: Running: startup.lua · 64 RPM, Stopped, or in amber Paused: needs rotation / Paused: overstressed when the computer isn't turning or its network is overstressed. It also shows the cursor's line and column.
  • Console under the code. Drag the divider above it to make it taller or shorter.
  • Side panel, picked from the activity bar on the right edge: Files, Redstone (what comes in and goes out on each side, live) and Flows, which will show what moves between machines and programs once the data bus arrives. Click the active icon or press Ctrl+B to hide it; drag its edge to resize it.

Drag any window edge to resize it. The window position and size, both dividers and the open panel are remembered across games in config/create_new_era-editor.properties.

Files and tabs#

  • New file: the + in the Files panel or Ctrl+N. Type a name and press Enter (Esc cancels). Without an extension, .lua is added. Names can use letters, numbers, _ - . /.
  • Open: click a file in the panel. It opens in a tab.
  • Rename: the rename button next to the file. Renaming the file that runs keeps it as the one that runs.
  • Delete: click the × next to the file, then again within three seconds to confirm. If you delete the last file, a fresh startup.lua appears.
  • Tabs: click to switch; close with the tab's ×, a middle-click or Ctrl+W. Ctrl+Tab cycles through them.

Files save on their own a moment after you stop typing, when you close a tab or the editor, and when you run. Ctrl+S saves right away.

Running#

Run (Ctrl+R) saves every open file and runs the file in the active tab. Stop (Ctrl+T) ends it and turns its outputs off. Clicking an error in the console opens the file it names at its line.

Suggestions#

A suggestion list opens as you type a name or after a ., and Ctrl+Space opens it anywhere. Move with ↑ ↓ or PgUp PgDn, accept with Tab or Enter, close with Esc. The pane beside the list shows the selected item's signature and what it does. Matching is fuzzy: gai finds getAnalogInput.

What it suggests depends on where the cursor is:

  • Functions and libraries a program can use (print, redstone, math…), and after redstone., string. and the other libraries, their members.
  • Side names inside the quotes of a redstone call: rs.getInput(" offers front, back…
  • File names inside require(".
  • Variables and functions from the file you're editing, and fields you've used on your own tables.
  • Keywords, and snippets that write a whole block for you:
SnippetWrites
forfor i = 1, … do … end
forpfor k, v in pairs(…) do … end
forifor i, v in ipairs(…) do … end
whilewhile … do … end
loopwhile true do … sleep(0) end
ifif … then … end
ifeif … then … else … end
fnfunction …() … end
lfnlocal function …() … end

Nothing pops up inside comments or ordinary strings.
