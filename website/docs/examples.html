Examples

Each one is a whole program: paste it into a file, then press Run. For one split across files, see Files and require.

Blink#

The program every new computer starts with. It pulses the top twice a second: put a lamp on the computer.

Lua
-- Blinks a redstone signal out of the top: put a lamp on it.
-- Edit me, then press Run (Ctrl+R).
while true do
  redstone.setOutput("top", true)
  sleep(0.5)
  redstone.setOutput("top", false)
  sleep(0.5)
end

Repeat a signal#

Copies whatever comes in on the left to the right, once a tick. Put a lever on the computer's left and a lamp on its right.

Lua
while true do
  rs.setOutput("right", rs.getInput("left"))
  sleep(0) -- waits one tick
end

Count pulses#

Counts rising edges on the left and prints the total each time it goes up.

Lua
local count, was = 0, false
while true do
  local on = rs.getInput("left")
  if on and not was then
    count = count + 1
    print("pulses: " .. count)
  end
  was = on
  sleep(0)
end

Fade up#

Raises the analog output on top from 0 to 15, then stops. The output stays at 15 after the program finishes.

Lua
for strength = 0, 15 do
  rs.setAnalogOutput("top", strength)
  sleep(0.25)
end
print("done after " .. os.clock() .. " s")

Read every side#

Prints the signal strength coming into each side once.

Lua
for _, side in ipairs(rs.getSides()) do
  print(side, rs.getAnalogInput(side))
end

Slow-down warning#

Lights a lamp on top while the shaft turns slower than 64 RPM in either direction, and prints the speed every five seconds. At 0 RPM the program itself pauses, so the lamp keeps its last state.

Lua
local last = 0
while true do
  local rpm = math.abs(os.speed())
  rs.setOutput("top", rpm < 64)
  if os.clock() - last >= 5 then
    print(rpm .. " RPM")
    last = os.clock()
  end
  sleep(0.5)
end
