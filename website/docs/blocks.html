Blocks and recipes

Every block and item in the mod, with its tooltip and its recipe as defined in the mod's data files. All of them sit in the Create: New Era creative tab, and each has a Ponder scene: hold W over the item in game.

Recipe slots show a letter; the key under each grid names the item and which mod it comes from. Item textures from Minecraft and Create aren't reproduced here.

Machines

Four full blocks built around Create's casings. They rotate with the wrench and are mined with a pickaxe.

Brass Computer

Block · create_new_era:brass_computer
Brass Computer

Runs Lua programs you write in its built-in editor. For now they work with redstone; the data bus comes next.

When running
The screen lights up. The program gets a slice of time every tick and keeps going while nobody watches.
Redstone
Every face is a side: front, back, left, right, top and bottom. Read signals with redstone.getInput, send them with redstone.setOutput.
When the world loads
A program that was running starts again from the top.
Controls
When R-Clicked
Opens the editor. Ctrl+R runs, Ctrl+T stops.
When Wrenched
Turns the computer. The sides turn with its front.

Works today. Right-click to open the editor; see the Lua API. The screen lights up while a program runs. Data bus access arrives with phase 3.

Brass Screen

Block · create_new_era:brass_screen
Brass Screen

Joins with its neighbours into one big display made of flip pixels that turn when they change.

Next to another screen
Screens facing the same way merge into one pane and the brass frame between them disappears.
Pixels
48 by 48 flip pixels per block. Pick square plates or round discs in the client config.
Controls
When Wrenched
Turns the screen. It joins whatever screens it now lines up with.

Joins today: screens facing the same way merge into one pane. Drawing on them arrives with phase 4, Flip-pixel screens.

Universal Adapter

Block · create_new_era:universal_adapter
Universal Adapter

Attach to any block to expose what it can do, kinetics, items or fluids, on the data bus.

When placed
Sticks to the face you click, so it fits on any side of a machine.
Coming soon
Arrives with the data bus. Until then it doesn't do anything.

What it does arrives with phase 3, Data bus. Today it can be placed, rotated with the wrench and mined.

Bearing Servo

Block · create_new_era:bearing_servo
Bearing Servo

Turns an attached contraption to an exact angle on command.

When placed
Faces you, like Create's bearings.
Coming soon
Programs will set its angle in degrees, for gimbals, turrets and flaps.

What it does arrives with phase 6, Aeronautics. Today it can be placed, rotated with the wrench and mined.

Panel controls

Small blocks you place on any face to build control desks. Each is a Control Plate plus one part. Wiring them to programs is phase 5; today they can be placed, rotated and mined.

Control Plate

Item · create_new_era:control_plate
Control Plate

Andesite base for every panel control.

Crafting
Combine with a part, like a lever or a nixie tube, to make a control.
