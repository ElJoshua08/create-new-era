Contributing

Pull requests are welcome: fixes, roadmap features, translations, docs. This is a summary of CONTRIBUTING.md, which has the details.

For anything big, open an issue first so the approach is agreed before you spend time on it.

Setting up#

A JDK 17 or newer to start Gradle; it fetches JDK 21 and the JetBrains Runtime itself. Then ./gradlew runClient, and ./gradlew hotswap to push code changes into the running game. See Live reloading and Dev runs.

Pull requests#

  • Branch from main. One focused change per pull request; don't reformat code you didn't otherwise touch.
  • Commit subjects in the imperative, saying what the change does (Show the shaft turning in a hole in the computer's back), with a body explaining the why when it isn't obvious.
  • When behaviour changes, update the README, these docs, and the in-game tooltip and Ponder text.
  • Contributions are released under The Unlicense, like the rest of the mod.

What must pass#

Terminal
./gradlew build                # compiles, builds the jar
./gradlew runGameTestServer    # in-game tests
./gradlew runData              # commit what it regenerates
  • Behaviour changes come with a new or updated GameTest in src/main/java/com/createnewera/gametest/; bug fixes with one that fails without the fix. See GameTests and datagen.
  • Generated files (blockstates, item models, loot tables, tags, en_us.json) are committed up to date.

Assets and style#

  • Models, textures and Ponder structures come from the scripts in tools/. Edit the script and re-run it; never hand-edit the output. See Asset tools.
  • Keep Create's look: study its assets, reuse its casings by reference, take colours from the palettes in gen_textures.py, and include an iso_render.py render in the PR.
  • Code matches the code around it. Comments explain why, not what.
  • New Lua functions go in LuaComputer and prelude.lua, and in LuaApi.java so the editor suggests them.

Translations#

English is generated: block names through Registrate's .lang(...) in ModBlocks, everything else in ModLang. Spanish, es_es.json, is hand-written and gets every new key. New languages are welcome as files next to it.

Reporting bugs#

Use the bug report form and include the Minecraft, NeoForge, Create and Create: New Era versions, your mod list, steps to reproduce (a Lua program that shows it is ideal), and logs/latest.log plus any crash report, uploaded to a paste site such as mclo.gs.
