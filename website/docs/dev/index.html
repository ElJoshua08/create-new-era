Development

How to build Create: New Era, run it with a realistic modpack, reload code without restarting, and test it. The mod is public domain, so fork it freely.

Quick start#

Terminal
git clone https://github.com/ElJoshua08/create-new-era.git
cd create-new-era
./gradlew runClient     # first run downloads the dev modpack into run/

You only need a JDK 17 or newer to start Gradle; it fetches the JDKs it needs (JDK 21, and the JetBrains Runtime for dev runs) on its own. On Windows use gradlew.bat.
