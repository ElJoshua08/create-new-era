Dev runs

runClient downloads a realistic modpack into run/ the first time, so the mod is tested against what players actually run.

  • Sodium, Lithium, ModernFix, FerriteCore, ImmediatelyFast, Entity Culling
  • Iris with Complementary Reimagined (enabled on first launch) and Unbound
  • Create: Aeronautics and Sable

Every file is pinned from Modrinth and checksum-verified (SHA-1); a mismatch stops the build. The mods go into the run folders like a real install, not onto the classpath, so client-only mods never reach the dev server. The server and GameTest runs use run/server/ and only get Aeronautics and Sable; datagen runs in run/data/. The shaderpack is picked once; after that, your in-game choice wins.

Switches#

In gradle.properties:

gradle.properties
dev_client_mods=true   # Sodium + optimization mods in runClient
dev_shaders=true       # Iris + Complementary shaderpacks in runClient
dev_aeronautics=true   # Create: Aeronautics + Sable in every run
dev_hotswap=true       # live code reloading, see Live reloading

To bump a version, replace its URL and SHA-1 in gradle/dev-mods.gradle. The downloads run as setupDevClient and setupDevServer before the matching run tasks.
