Project layout

A map of the repository.

src/main/java/com/createnewera/ CreateNewEra.java mod entry point, registers config and content CreateNewEraClient.java client setup: config screen, editor block/ block classes (screens, panel parts, machines) computer/ Brass Computer: block, block entity, Lua VM, files, sides client/editor/ the in-game editor: code view, completions, Lua API list, layout network/ payloads between the editor and the computer ponder/ Ponder scenes registry/ blocks, items, block entities, creative tab, lang config/ client config gametest/ GameTests src/main/resources/ data/create_new_era/lua/prelude.lua turns the Java side into the Lua API data/create_new_era/recipe/ recipes assets/create_new_era/ models, textures, Ponder structures, es_es src/generated/resources/ datagen output (don't edit by hand) gradle/ dev-mods.gradle the dev modpack hotswap.gradle live code reloading tools/ asset and dev scripts website/ this site

Where to start#

  • Adding to the Lua API: the Java side is in computer/LuaComputer.java (the native table); prelude.lua turns it into globals. Add the new names to client/editor/LuaApi.java so the editor suggests them.
  • The editor: client/editor/ComputerEditorScreen.java (window, panels, tabs), CodeEditor.java (text editing), Completions.java (what to suggest).
  • A computer's disk: computer/ComputerFiles.java, with the limits.
  • New block: register it in registry/ModBlocks.java, generate its model with tools/models/gen_models.py, then ./gradlew runData.
